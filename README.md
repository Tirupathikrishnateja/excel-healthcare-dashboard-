# Healthcare Analytics Dashboard | Microsoft Excel

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel to organize, analyze, and visualize healthcare-related data through a dashboard.

The dashboard is designed to make healthcare information easier to explore by presenting relevant metrics, summaries, and trends in a structured reporting format. It demonstrates how spreadsheet-based analysis can support data interpretation and reporting.

## 🎯 Project Objectives

- Organize and analyze structured healthcare data.
- Summarize healthcare-related indicators.
- Explore patterns and trends in the available dataset.
- Compare metrics across relevant categories.
- Present findings through charts, summary tables, and dashboard visuals.
- Demonstrate practical Excel skills for data analysis and business reporting.
